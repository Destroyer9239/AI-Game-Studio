# Asset tracking

Temporary fighter and building fixtures reuse original studio Blender sources through
tools/unreal/export_static.py. The three buildings belong to setup acceptance only,
not the planned station art. Concrete is the existing Poly Haven material with its
provenance under the shared assets; no new assets acquired for this setup.
Record new asset source, license, author, scale/orientation, texture sizes, triangle
budget, collision and visual review here. Existing rigged assets need a dedicated route.
